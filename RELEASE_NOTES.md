# 0.2.0-preview.1

Combined Windows and Android preservation preview based on touchHLE v0.3.0.

- Both launchers provide optional starter dragon encounters, 50:1 silver exchange
  and removal of the local arena cooldown.
- Windows uses landscape/layout corrections and a private local profile.
- Android retains iPhone Retina and save import/export.
- Common source delivery, rebuilt packages, revised setup/build instructions
  and per-platform license inventories accompany the release.

See VALIDATION.md for evidence and KNOWN_ISSUES.md for open limits.
